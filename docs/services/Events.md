# Events

`EventsService` — идущие сейчас LiveOps-ивенты.

## Что делает сервис, а что делает сервер

**Сервис не включает ивенты.** Пока акция идёт, сервер уже отдаёт этому игроку другие значения
экономики — цены, лимиты, награды, — и игра, которая не вызывает отсюда ничего, всё равно их получает.
Чего она без этого сервиса не может — **сказать об этом**: показать баннер, отвести отсчёт до конца
акции, открыть экран только той аудитории, на которую ивент нацелен.

Поэтому если акция «не работает» — дело не в интеграции сервиса. Смотрите ивент и оверрайды в консоли.

## Методы

- `GetActiveEventsAsync(bool includeUnmatched = false)` → `ActiveEventsDto` — что идёт сейчас.
  `includeUnmatched: true` добавит ивенты чужих аудиторий с `isMatched = false` — это для экрана
  поддержки или отладки; в игровом UI такой список обещает игроку недоступное.
- `TryGetEvent(key, out ActiveEvent)` — достать из кеша по ключу.
- `IsEventActive(key)` — идёт **и** относится к этому игроку.
- `IsEventActive(key, requireMatched: false)` — идёт вообще, без учёта аудитории.
- `GetTimeLeft(key)` / `GetTimeUntilNextOccurrence(key)` — сколько осталось / когда откроется снова.
- `Clear()` — сбросить кеш (вызывается сам, см. ниже).

## Свойства

| | |
|---|---|
| `MyEvents` | то, что относится к этому игроку — на этом строится UI |
| `ActiveEvents` | всё, что пришло в последнем ответе |
| `IsLoaded` | был ли успешный запрос после входа или смены профиля |
| `IsStale` | ответ пережил срок, который назвал сервер |
| `ServerUtcNow` | «сейчас» по часам сервера |
| `ClockOffset` | расхождение часов сервера и устройства с последнего запроса |
| `Generation` | не изменился ⇒ набор тот же |

## Ключ, а не идентификатор

Ивент адресуется `Key` — тем, что задали в консоли:

```csharp
if (Sdk.Events.IsEventActive("halloween_2026"))
{
    ShowHalloweenTab();
}
```

Идентификатора документа в SDK нет намеренно: правка ивента в ветке, где он общий, копирует запись и
выдаёт новый id, так что игра, сохранившая его, потеряла бы ивент на первом же редактировании.

## «Идёт» и «идёт для меня» — разные вопросы

У ивента может быть правило аудитории. `IsMatched` говорит, попадает ли под него **этот** игрок;
`IsTargeted` — есть ли правило вообще, то есть «для всех» это или «идёт, но не для тебя».

`IsEventActive(key)` по умолчанию требует попадания в аудиторию — гейт контента спрашивает именно это.

## Когда перезапрашивать

Это **не** часть прогрева на сплэше, в отличие от конфигурационных сервисов: ответ зависит от игрока и
верен минуты. Запрашивайте, когда экран его показывает, и перезапрашивайте по `IsStale` — сервер сам
говорит, до какого момента ответ точен (обычно это ближайшее открытие или закрытие окна).

Автоматического опроса и C#-событий «ивент начался/кончился» нет: сокета у сервиса нет, и такое
событие срабатывало бы в момент, который выбрал сам вызывающий, то есть врало бы про время.

## Время и часы устройства

Все метки — абсолютный UTC. Часы устройства врут достаточно часто, чтобы отсчёт, построенный на них,
было видно невооружённым глазом, поэтому сервис на каждом запросе запоминает расхождение с часами
сервера и считает всё от `ServerUtcNow`.

`StartsAtUtc` / `EndsAtUtc` — границы **текущего окна**, а не всей кампании. Для «акция до 31 декабря»
есть `ScheduleEndsAtUtc`.

## Смена профиля сбрасывает кеш

Аудитория считается по профилю, поэтому при входе и при `SelectProfileAsync` кеш очищается: прежний
ответ описывает другого игрока. Сброс, а не перезапрос — когда список снова нужен, решает игра.

## Рецепты

**Баннер с отсчётом**

```csharp
var op = Sdk.Events.GetActiveEventsAsync();
op.UseCompleted(_ =>
{
    if (!Sdk.Events.TryGetEvent("halloween_2026", out var halloween)) return;

    banner.Show(halloween.Name);
    banner.SetProgress(halloween.Progress(Sdk.Events.ServerUtcNow));
});

// в обновлении раз в секунду:
var left = Sdk.Events.GetTimeLeft("halloween_2026");
label.text = left == null ? string.Empty : Format(left.Value);
```

**Гейт контента**

```csharp
shopTab.SetActive(Sdk.Events.IsEventActive("vip_sale"));
```

**Опрос по IsStale**

```csharp
if (Sdk.Events.IsStale)
{
    Sdk.Events.GetActiveEventsAsync();
}
```

## Пустой список — это норма

`events: []` значит «сервис работает, ивентов сейчас нет» — обычное состояние большинства проектов.
Ошибкой это не является; рисуйте пустое состояние, а не сообщение о сбое.
